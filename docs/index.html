Як встановити

Потрібен iPhone, застосунок Scriptable і сповіщення Telegram-каналу ЖК.

КРОК 01

Встановіть Scriptable

Завантажте Scriptable з App Store. Увімкніть iCloud Drive для Scriptable та дозвольте сповіщення.

КРОК 02

Завантажте ZIP

Завантажте архів v1.0.1, розпакуйте у «Файлах». Скопіюйте лише INSTALL.js до iCloud Drive → Scriptable.

КРОК 03

Виберіть адресу

Запустіть INSTALL у Scriptable та виберіть свою адресу. Створяться дев'ять скриптів. Додайте потрібні віджети Scriptable на екран.

🔔 Обов'язково: вступіть у Telegram-канал «🔊 ЖК Республіка: Сповіщення» та увімкніть сповіщення для нього. Дозвольте Telegram показувати сповіщення в налаштуваннях iOS. Без системних сповіщень автоматичне оновлення може не працювати.

Налаштування автоматизації

У «Командах» (Shortcuts) створіть дві окремі автоматизації на системні сповіщення Telegram. Для обох — фільтр заголовка без емодзі.

1. Статус світла

When I receive a notification
  from: Telegram
  Title contains:
    ЖК Республіка: Сповіщення
  Automation: ON
  Notify: OFF

Run → Республіка · Світло вдома
  with: Notification → Body

2. Імпорт графіка

When I receive a notification
  from: Telegram
  Title contains:
    ЖК Республіка: Сповіщення
  Automation: ON
  Notify: OFF

Run → Республіка · Імпорт графіка
  with: Notification → Body
  Run In App: OFF
  Show When Run: OFF
Зверніть увагу: Notify: OFF у Shortcuts вимикає додаткове сповіщення самої автоматизації — не вимикайте сповіщення Telegram-каналу. Якщо ви перебуваєте всередині каналу та Telegram не показує системного сповіщення, автоматизація може не запуститися. Повідомлення також можуть бути обрізаними.

Питання та підтримка

Чи треба реєструватися або платити?

Ні, скрипти безкоштовні. Потрібен iPhone та Scriptable. Власного сервера або Telegram-бота немає.

Якщо пропущено повідомлення про світло?

Скористайтеся службовим скриптом «Республіка · Відновити подію світла» та введіть підтверджений час перемикання. Не створюйте вигаданих подій.

Як повідомити про помилку?

Напишіть у Telegram @cherkungt або відкрийте GitHub Issues. Не публікуйте особисті дані, токени та паролі.

Чи всі повідомлення гарантовано фіксуються?

Ні. Дані надходять через системні сповіщення Telegram та iOS Shortcuts. Пропущені або обрізані сповіщення можуть вплинути на статистику та імпорт графіка.

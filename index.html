Встановлення за 5 кроків

Не потрібно програмувати або налаштовувати сервер. Достатньо виконати ці кроки на iPhone.

1

Установіть Scriptable

Знайдіть Scriptable в App Store. Дозвольте застосунку доступ до iCloud Drive, якщо використовуєте синхронізацію.

2

Завантажте ZIP

Завантажте архів v1.0.1 та розпакуйте його в застосунку «Файли».

3

Скопіюйте INSTALL.js

Перенесіть тільки файл INSTALL.js до «Файли → iCloud Drive → Scriptable». Папку source копіювати не потрібно.

4

Запустіть установник

У Scriptable відкрийте INSTALL, натисніть запуск і виберіть адресу. Установник створить дев'ять скриптів «Республіка · …».

5

Додайте віджети на екран

Утримуйте головний екран → «+» → Scriptable → оберіть розмір і додайте. У параметрах віджета вкажіть відповідний скрипт «Республіка · …».

Важливо: щоб стан світла й графіки оновлювалися автоматично, треба окремо налаштувати дві автоматизації Telegram → Команди. Нижче — точна схема.

Автоматичне оновлення

Дві автоматизації в стандартному застосунку Apple «Команди» отримують текст системних сповіщень із Telegram та передають його скриптам.

Підготовка Telegram

  1. Приєднайтеся до каналу «🔊 ЖК Республіка: Сповіщення».
  2. Увімкніть сповіщення саме цього каналу — він не повинен бути вимкненим (muted).
  3. Дозвольте системні сповіщення для Telegram в налаштуваннях iOS.

Автоматизація №1 — стан світла

  1. Відкрийте Команди (Shortcuts) — стандартний застосунок Apple для автоматизацій. Якщо його немає, завантажте з App Store. Далі: Команди (Shortcuts) → Автоматизація → «+» → «Коли отримую сповіщення» → Telegram.
  2. Фільтр: Title → contains → ЖК Республіка: Сповіщення (без 🔊).
  3. Automation ON, Notify OFF.
  4. Дія Scriptable → Run Script → Республіка · Світло вдома.
  5. Поле with → Notification → Body.
Telegram notification → Title contains "ЖК Республіка: Сповіщення" ↓ Run Script "Республіка · Світло вдома" with: Notification → Body

Автоматизація №2 — графіки

  1. У застосунку Команди (Shortcuts) створіть другу автоматизацію для сповіщень Telegram.
  2. Фільтр той самий: Title → contains → ЖК Республіка: Сповіщення.
  3. Automation ON, Notify OFF.
  4. Scriptable → Run Script → Республіка · Імпорт графіка.
  5. with → Notification → Body; якщо доступні, Run In App OFF і Show When Run OFF.
Telegram notification → Title contains "ЖК Республіка: Сповіщення" ↓ Run Script "Республіка · Імпорт графіка" with: Notification → Body

Параметр «Notify OFF» у Командах вимикає лише додаткове сповіщення автоматизації. Сповіщення самого Telegram мають залишатися увімкненими.

Питання та відповіді

Що варто знати перед встановленням.

Чи потрібна реєстрація?

Ні. Скрипти працюють локально на iPhone та не вимагають окремого облікового запису для цього комплекту. Потрібні Scriptable, Telegram і Команди.

Чому віджет не показує історію за минулий місяць?

Історія починається з першої розпізнаної події після налаштування. Комплект не вигадує минулі вмикання та вимикання.

Чому віджет іноді не оновлюється?

Команди залежать від отриманих системних Telegram-сповіщень. Якщо сповіщення не з'явилося, ви читаєте повідомлення всередині каналу або текст сповіщення обрізаний, автоматизація може не отримати потрібні дані.

Що робити, якщо пропущено перемикання світла?

У Scriptable запустіть «Республіка · Відновити подію світла» та введіть дату, час і стан з оригінального повідомлення. Спершу перевірте історію, щоб не дублювати подію.

Чи можна натиснути на «План vs Факт»?

Так. Цей віджет відкриває детальний звіт за день, тиждень і місяць.

Чи передаються мої дані комусь?

Скрипти зберігають свої робочі дані локально в Scriptable. Сайт не збирає ваші дані, не має форми входу і не звертається до персональних файлів на телефоні.

Що робити, якщо щось не працює?

Напишіть автору в Telegram або створіть GitHub Issue. Зазначте, яка саме автоматизація чи віджет не працюють, але не публікуйте приватну інформацію.

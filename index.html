Встановлення без складних налаштувань

Оберіть свій випадок. Кожен пункт можна розгорнути й виконати по черзі. Для актуального світла потрібен API-токен, а для планових графіків — окрема автоматизація Telegram.

1 Установіть Scriptable та Команди

На iPhone встановіть Scriptable. Знайдіть стандартний застосунок Apple «Команди» (Shortcuts) — він знадобиться для графіків. Telegram також має бути встановлений.

2 Отримайте персональний API-токен
  1. Відкрийте кабінет мешканця.
  2. Увійдіть через Telegram і пройдіть перевірку мешканця.
  3. Створіть персональний API-токен, який починається з rsp_, та скопіюйте його.

Не надсилайте токен нікому й не публікуйте скриншоти з ним. Токен зберігається локально на вашому iPhone.

3 Завантажте установник у Scriptable

Завантажити ZIP v2.0.3

  1. Відкрийте ZIP у застосунку «Файли» та розпакуйте.
  2. Перемістіть INSTALL.js у iCloud Drive → Scriptable.
  3. Відкрийте Scriptable: має з'явитися скрипт INSTALL.
Немає папки Scriptable в iCloud? Це не означає, що все зламалося. Як альтернатива: у Scriptable натисніть + → створіть новий скрипт → відкрийте код INSTALL.js у браузері → скопіюйте весь код і вставте його у новий скрипт → назвіть його INSTALL та збережіть. Якщо iCloud вимкнений, увімкніть iCloud Drive для Scriptable в налаштуваннях iPhone; установнику потрібна можливість зберігати скрипти.
4 Запустіть установник і виберіть адресу
  1. У Scriptable натисніть на INSTALL і запустіть його (▶).
  2. Виберіть свою адресу ЖК.
  3. Вставте API-токен, натисніть «Продовжити», а потім «Установити».
  4. Після завершення з'являться скрипти з назвою «Республіка · …».

Увага: поява скриптів ще не означає, що віджети й графіки налаштовані. Попереду ще два важливі кроки.

5 Додайте віджети на головний екран
  1. Затисніть порожнє місце на екрані iPhone → «Змінити» або «+» → «Додати віджет».
  2. Знайдіть Scriptable і виберіть розмір.
  3. Затисніть сам віджет → «Редагувати віджет» → поле Script.
  4. Для малого віджета виберіть Республіка · Світло вдома; для графіків — Республіка · Графік сьогодні+завтра.
  5. Залиште When Interacting → Run Script, Parameter — порожнім.

6 Обов'язково підключіть Telegram-графіки

Без автоматизації віджет із плановими графіками може бути порожнім, навіть якщо «Світло вдома» працює через API. Покрокова візуальна інструкція нижче ↓.

Оновлення — 3 кроки. Історія та графіки збережуться. Не видаляйте JSON-файли.

1 Запустіть новий установник

Завантажте ZIP v2.0.3, замініть INSTALL.js та запустіть його в Scriptable. Виберіть адресу й введіть API-токен. На пропозицію очистити старі скрипти поки натисніть «Залишити поки».

Якщо установник не відкривається, перегляньте альтернативний спосіб через +.

2 Перемкніть віджети та автоматизацію

Віджети: затисніть віджет → «Редагувати віджет» → Script → виберіть новий скрипт Республіка · … з таблиці.

Графіки: у «Команди → Автоматизація → Імпорт Графіка» змініть старий скрипт на Республіка · Імпорт графіка. Залиште Notification → Body й переконайтеся, що автоматизація ввімкнена. Якщо автоматизації немає, створіть її за наочною інструкцією. Стару «Світло вдома» вимкніть.

3 Перевірте й приберіть зайве

Перевірте «Світло вдома», попередню статистику та графіки. Потім ще раз запустіть INSTALL і погодьтеся архівувати старі скрипти. Історія, токен і графіки залишаться.

Перевірка результату: статус світла має з'являтися через API; графік — після отримання повного Telegram-повідомлення; статистика у нового користувача накопичується поступово. Якщо графіка ще немає, це не завжди помилка: він міг ще не надходити після налаштування автоматизації.
Найважливіший крок для графіків

Автоматизація Telegram — показуємо кожен натиск

Це робиться вручну в Apple «Команди», не в Scriptable. Якщо цей крок пропустити, графіки не надходитимуть автоматично. Нижче — схематичний вигляд екранів iPhone (підписи можуть трохи відрізнятися залежно від мови iOS).

1 Відкрийте «Команди» → «Автоматизація»

У Telegram увімкніть сповіщення каналу «🔊 ЖК Республіка: Сповіщення» та сповіщення Telegram в iOS. Потім у «Командах» відкрийте вкладку «Автоматизація» (Automation), натисніть +. Оберіть тригер «Коли отримую сповіщення» (When I Get a Notification) та застосунок Telegram.

У заголовку повідомлення налаштуйте фільтр Title → contains → ЖК Республіка: Сповіщення (без 🔊). Автоматизація має запускатися без додаткового підтвердження.

2 Додайте дію Scriptable → Run Script

На екрані дій натисніть пошук, введіть Scriptable та оберіть Run Script. Натисніть синю назву скрипта й оберіть Республіка · Імпорт графіка. Не «Світло вдома» й не старий «Імпорт графіка».

Імпорт Графіка
🔔 When I receive a notification
from Telegram
Title contains ЖК Республіка: Сповіщення
🔷 Run Республіка · Імпорт графіка
with 🔔 Body ✓
Схема, не справжній скриншот. Назви перевіряйте за текстом.
3 Як знайти «Notification → Body» — тут найчастіше помиляються

Важливо: слово «Notification» може НЕ показуватися одразу. Це прихований вибір змінної в «Командах».

  1. В дії Run Script знайдіть слово після with. Там може стояти Shortcut Input, інша синя змінна або порожнє значення.
  2. Натисніть і УТРИМУЙТЕ синю змінну в полі with, щоб відкрити меню вибору змінної. Якщо коротке натискання не показує потрібного меню — саме утримуйте.
  3. У меню виберіть Notification (значок дзвіночка 🔔). Якщо воно вже вибране, натисніть синій Body, щоб відкрити тип властивості.
  4. У переліку Get виберіть Body — не Title і не Subtitle.
  5. Поверніться до дії. Має бути написано Run Республіка · Імпорт графіка with 🔔 Body.

4 Перевірте перемикачі та збережіть

Розгорніть додаткові параметри дії Run Script (стрілка вниз): Run In App → OFF, Show When Run → OFF. Поля Texts, URLs, Images, Files залиште порожніми. Автоматизація має бути увімкнена, без запиту підтвердження; якщо доступна опція сповіщення про запуск — її можна вимкнути.

✅ Готово, якщо: у вкладці «Автоматизація» є одна активна автоматизація «Імпорт Графіка» з Telegram → Scriptable і правильним Body. Для «Світло вдома» Telegram-автоматизація більше не потрібна — статус приходить через API.

Якщо щось не працює

«Script not found»

Затисніть віджет → «Редагувати віджет» → Script → відповідний Республіка · … із таблиці. Не видаляйте історію.

«Немає даних» у віджеті світла

У Scriptable запустіть Республіка · Світло вдома. Перевірте вибрану адресу й токен. Помилку можна побачити через Республіка · Діагностика → «Помилки і пропуски».

Графіки не з'являються

Увімкніть сповіщення каналу Telegram. Перевірте автоматизацію з Республіка · Імпорт графіка та Notification → Body — дивіться підказку. Графік з'явиться після отримання відповідного повідомлення.

Де знайти логи?

Scriptable → Республіка · Діагностика → «Помилки і пропуски» або «Скопіювати 50 записів». Перед відправленням перевірте журнал на приватну інформацію.

Чому неповна статистика?

У нових користувачів історія накопичується з першої перевірки API. iOS контролює частоту оновлення, а API не повертає повної минулої історії.

Що з персональним токеном?

Сайт його не збирає. Він зберігається в Keychain iPhone й використовується для HTTPS-запитів до API.

Встановлення та оновлення

Неважливо, встановлюєте вперше чи оновлюєте стару версію: пройдіть ці самі кроки. Якщо щось уже встановлено й працює, просто перевірте цей крок і йдіть далі. Історію світла та файли JSON не видаляйте.

1 Підготуйте Scriptable та персональний токен

На iPhone відкрийте застосунок App Store та встановіть Scriptable (якщо вже встановлений — пропустіть). Потім у Safari відкрийте кабінет мешканця, авторизуйтеся через Telegram та скопіюйте особистий API-токен rsp_….

Якщо токен уже є — використайте його. Нікому не надсилайте токен.

2 Завантажте INSTALL.js

Завантажити ZIP v2.0.3

  1. На iPhone відкрийте застосунок «Файли» та знайдіть завантажений ZIP (зазвичай у папці «Завантаження»). Натисніть на ZIP, щоб розпакувати його.
  2. Не виходячи із застосунку «Файли», відкрийте розпаковану папку, затисніть файл INSTALL.js → «Перемістити» → iCloud Drive → папка «Scriptable». Якщо цей файл там уже є, замініть його новим.
  3. Тепер закрийте «Файли» й відкрийте саме застосунок Scriptable (іконку на головному екрані iPhone, не папку в «Файлах»). У списку скриптів має з'явитися INSTALL.
У застосунку «Файли» немає папки Scriptable? Натисніть сюди

На iPhone відкрийте застосунок Scriptable → натисніть + для створення скрипта. Окремо в Safari відкрийте повний код INSTALL.js, скопіюйте його та вставте в редактор нового скрипта в застосунку Scriptable. Назвіть скрипт INSTALL. Якщо такий скрипт уже є, замініть його старий код новим. Дозвольте Scriptable доступ до iCloud Drive, адже установник зберігає туди робочі скрипти.

3 Запустіть установник
  1. Відкрийте на iPhone застосунок Scriptable (не папку Scriptable в застосунку «Файли»). У списку скриптів знайдіть INSTALL і просто натисніть на нього один раз — відкриється установник.
  2. У вікні установника виберіть адресу ЖК, вставте токен і натисніть «Установити».
  3. Поверніться до списку в застосунку Scriptable: там мають з'явитися скрипти з префіксом Республіка ·.
Якщо оновлюєте: на запит архівувати старі скрипти зараз натисніть «Залишити поки». Спочатку перепризначте віджети та автоматизацію, інакше вони можуть показати «Script not found».
4 Додайте або переналаштуйте віджети

Якщо віджетів ще немає: вийдіть із застосунку Scriptable на головний екран iPhone, затисніть порожнє місце → «Змінити» / «+» → «Додати віджет» → Scriptable → виберіть розмір.

Якщо віджети вже є: на головному екрані iPhone нові не додавайте. Затисніть кожен → «Редагувати віджет» → Script → виберіть відповідний скрипт Республіка · ….

Для всіх: When Interacting → Run Script, Parameter залиште порожнім. Потрібні назви:

5 Підключіть графіки через Telegram

Цей крок потрібен усім: без автоматизації графіки на сьогодні й завтра не імпортуються автоматично.

Якщо автоматизації немає: відкрийте застосунок Apple «Команди» та створіть її за наочною інструкцією нижче.

Якщо автоматизація вже є: відкрийте застосунок «Команди» → вкладка «Автоматизація» → «Імпорт Графіка» → у дії Run Script виберіть Республіка · Імпорт графіка замість старої назви. Перевірте with → Notification → Body та ввімкнений стан.

Стару автоматизацію для «Світло вдома» вимкніть: тепер фактичний стан береться з API.

6 Перевірте результат

Відкрийте застосунок Scriptable і запустіть скрипт Республіка · Світло вдома — має відображатися стан з API. Перевірте статистику: попередні дні зберігаються, якщо ви оновлювалися; у нових користувачів вона накопичується поступово.

Графіки можуть з'явитися не одразу: потрібне отримане повідомлення Telegram з планом або ручний імпорт.

Оновлювалися і все працює? Можна у застосунку Scriptable повторно запустити INSTALL та погодитися архівувати старі скрипти. Це необов'язково: дані та історію не видаляйте.

Готово. «Світло вдома» використовує API; Telegram потрібен тільки для планових графіків. Якщо щось не працює — коротка допомога внизу.
Реальні екрани iPhone · Apple «Команди»

Налаштування Telegram-графіків

Один раз створіть автоматизацію в «Командах». Нижче — справжні скриншоти з iPhone, а не намальовані приклади. Натискайте на зображення, щоб відкрити їх у повному розмірі. Англійські написи на скринах пояснені українською.

Перед початком: у Telegram підпишіться на канал «🔊 ЖК Республіка: Сповіщення» та увімкніть його сповіщення. Також дозвольте сповіщення Telegram в налаштуваннях iPhone.
1 Знайдіть дію «Сповіщення»

«Команди» → «Автоматизація» → «+». Якщо бачите екран New Shortcut, у нижньому пошуку натисніть Automation («Автоматизація») та знайдіть Notification («Сповіщення») з червоним дзвіночком.

2 Виберіть Telegram і налаштуйте фільтр

Встановіть застосунок Telegram. Натисніть + Add Filter («Додати фільтр»). У рядку Title contains Title («Заголовок містить…») торкніться другого синього Title після contains і введіть ЖК Республіка: Сповіщення без емодзі.

Розкрийте синю стрілку біля Telegram. Має бути Automation ON («Автоматизація увімкнена»), Notify OFF («Повідомляти вимкнено»).

Увага: на наступних скриншотах поле Title ще не заповнене. Обов'язково впишіть назву каналу, інакше автоматизація не ввімкнеться.
3 Додайте «Запустити скрипт»

У нижньому пошуку введіть Run («Запуск») і виберіть Run Script («Запустити скрипт») зі значком { } — не Run Shortcut. Натисніть синє Script («Скрипт») та виберіть Республіка · Імпорт графіка.

4 Знайдіть приховану змінну «Сповіщення»

Після слова with («з») знайдіть синє Parameter («Параметр»). Натисніть і утримуйте цей синій напис, щоб відкрити меню. Оберіть 🔔 Notification («Сповіщення»).

5 Виберіть «Текст повідомлення» (Body)

Натисніть і утримуйте синє Notification у дії Run Script, щоб відкрити список властивостей Get («Отримати»). Виберіть Body («Текст»), не Title і не Subtitle. Саме Body передає весь доступний текст Telegram-сповіщення імпортеру.

6 Перевірте та збережіть

У результаті має бути Run «Республіка · Імпорт графіка» with 🔔 Body. Title contains ЖК Республіка: Сповіщення має бути заповнено, Automation ON, Notify OFF. У додаткових параметрах Run Script установіть Run In App OFF і Show When Run OFF, якщо ці опції доступні.

Готово! Планові графіки почнуть надходити після наступного відповідного сповіщення Telegram. Фактичний стан «Світло вдома» працює через API та не залежить від автоматизації.

Якщо щось не працює

«Script not found»

Затисніть віджет → «Редагувати віджет» → Script → відповідний Республіка · … із таблиці. Не видаляйте історію.

«Немає даних» у віджеті світла

У застосунку Scriptable запустіть Республіка · Світло вдома. Перевірте вибрану адресу й токен. Помилку можна побачити через Республіка · Діагностика → «Помилки і пропуски».

Графіки не з'являються

Увімкніть сповіщення каналу Telegram. Перевірте автоматизацію з Республіка · Імпорт графіка та Notification → Body — дивіться підказку. Графік з'явиться після отримання відповідного повідомлення.

Де знайти логи?

Застосунок Scriptable → Республіка · Діагностика → «Помилки і пропуски» або «Скопіювати 50 записів». Перед відправленням перевірте журнал на приватну інформацію.

Чому неповна статистика?

У нових користувачів історія накопичується з першої перевірки API. iOS контролює частоту оновлення, а API не повертає повної минулої історії.

Що з персональним токеном?

Сайт його не збирає. Він зберігається в Keychain iPhone й використовується для HTTPS-запитів до API.

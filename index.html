Встановлення API v2.0.2

Поточний стан світла береться з API мешканця. Для графіків продовжує працювати Telegram.

1

Установіть Scriptable

Scriptable в App Store та дозвольте доступ до iCloud Drive.

2

Отримайте персональний API-токен

Відкрийте кабінет мешканця, увійдіть через Telegram, пройдіть перевірку доступу та створіть особистий API-токен (починається з rsp_). Скопіюйте токен: його потрібно ввести під час установлення. Не публікуйте й нікому не надсилайте токен.

3

Завантажте ZIP v2.0.2

Завантажити архів v2.0.2, розпакуйте його у застосунку «Файли» й перемістіть INSTALL.js до «iCloud Drive → Scriptable». Пряме посилання на установник — резервний варіант.

4

Виберіть адресу та введіть токен

Відкрийте Scriptable → INSTALL → запуск. Виберіть одну з 13 адрес, вставте API-токен. Установник перевірить його та створить скрипти «Республіка · …» без «ТЕСТ» у назві. Токен зберігається у захищеному сховищі Keychain на вашому iPhone.

5

Додайте віджети та імпорт графіків

Установник створює скрипти, але не додає віджети автоматично. Дивіться розділ «Як додати віджети на iPhone»: там є розміри, точні назви та виправлення «Script not found». Для планових графіків потрібна лише одна автоматизація Telegram.

Оновлення з v1.0.1: установник зберігає старі файли історії та графіків, робить резервну копію історії та переносить її в API-статистику. Не видаляйте файли .json вручну. Вимкніть попередню автоматизацію Telegram для «Світло вдома»: відтепер фактичний стан отримуємо з API.
Автоматичне прибирання старих скриптів: після встановлення v2.0.2 установник запропонує перенести застарілі й тестові .js у папку «Архів старих скриптів». Підтверджуйте це лише після перепризначення віджетів на «Республіка · …» та оновлення автоматизації Telegram на «Республіка · Імпорт графіка». Файли .json, історія світла, графіки й токени залишаються без змін.
Обмеження iOS: оновлення віджета у фоні контролює iOS. Перевірка API не гарантується щохвилини, а пропущені між перевірками перемикання не завжди можна відновити без історії на сервері.

Як додати віджети на iPhone

Після запуску INSTALL.js скрипти з'являться у Scriptable. Самі віджети на головному екрані потрібно додати й прив'язати до скриптів вручну — установник не може зробити це за вас.

1

Додайте Scriptable на екран

На головному екрані iPhone натисніть і потримайте порожнє місце → «Змінити» / «+» → «Додати віджет» → знайдіть Scriptable → виберіть розмір → «Додати віджет».

2

Призначте правильний скрипт

Натисніть і потримайте щойно доданий віджет → «Редагувати віджет» → натисніть рядок Script → виберіть скрипт «Республіка · …» із таблиці нижче. Назви з «ТЕСТ» більше не використовуйте.

3

Залиште стандартну дію

When Interacting → Run Script залишайте без змін. Поле Parameter залиште порожнім. Закрийте налаштування віджета й перевірте його.

Для екрана блокування: затисніть екран блокування → «Налаштувати» → виберіть область віджетів → Scriptable → призначте скрипт для Lock Screen. Якщо такий варіант розміру віджета не підтримується вашою версією Scriptable, використовуйте «Світло вдома» на головному екрані.

Бачите «Script not found.»? Це означає, що віджет і досі прив'язаний до старого скрипту, який перейменували або перенесли в архів. Не перевстановлюйте API та не видаляйте історію. Натисніть і потримайте віджет з помилкою → «Редагувати віджет» → рядок «Script» → виберіть новий Республіка · … відповідно до таблиці. Закрийте налаштування. Якщо віджет не оновився, відкрийте відповідний скрипт у Scriptable, запустіть його один раз і поверніться на головний екран. Можна також видалити тільки віджет і додати його наново — це не видаляє дані Scriptable.
Перед очищенням: спочатку перепризначте всі віджети й автоматизацію імпорту графіків на нові скрипти. Коли установник пропонує архівувати старі скрипти до цього кроку — виберіть «Залишити поки». Після перевірки запустіть INSTALL.js повторно й архівуйте зайве. Файли .json не видаляйте.

Telegram потрібен лише для графіків

API відповідає за фактичний стан світла, Telegram — за планові графіки на сьогодні й завтра.

Підготовка Telegram

  1. Підпишіться на канал «🔊 ЖК Республіка: Сповіщення».
  2. Увімкніть сповіщення саме цього каналу.
  3. Дозвольте системні сповіщення Telegram в налаштуваннях iPhone.

Єдина потрібна автоматизація — імпорт графіків

  1. Відкрийте Команди (Shortcuts) → «Автоматизація» → «+» → «Коли отримую сповіщення» → Telegram.
  2. Фільтр: Title → contains → ЖК Республіка: Сповіщення (без 🔊).
  3. Automation ON, Notify OFF.
  4. Дія: Scriptable → Run Script → Республіка · Імпорт графіка.
  5. Поле: with → Notification → Body. Якщо доступні: Run In App OFF, Show When Run OFF.
Telegram notification → Title contains "ЖК Республіка: Сповіщення" ↓ Run Script "Республіка · Імпорт графіка" with: Notification → Body

Для користувачів v1.0.1: вимкніть стару автоматизацію «Світло вдома». Її більше не потрібно використовувати для обліку фактичних перемикань. Наявні графіки та історію не видаляйте.

Питання та відповіді

Що варто знати перед встановленням.

Чи потрібна реєстрація?

Так. Для API потрібна верифікація в кабінеті мешканця через Telegram та персональний токен: https://chatbot.respublika.pp.ua/resident/. Для графіків також потрібні Telegram та Команди.

Чому віджет не показує історію за минулий місяць?

Для нових установлень історія починається з першого підтвердженого стану API. Під час оновлення з v1.0.1 старі події Telegram зберігаються й переносяться. Непомічені API перемикання за минулі дні відновити автоматично неможливо.

Чому віджет іноді не оновлюється?

iOS сама визначає час фонового оновлення Scriptable. API перевіряється під час виконання віджета; сповіщення Telegram потрібні лише для планових графіків.

Що робити, якщо пропущено перемикання світла?

API наразі не повертає повний журнал минулих перемикань. Якщо між двома перевірками було кілька змін, статистика може бути неповною; не вважайте її точною без підтвердження.

Чи можна натиснути на «План vs Факт»?

Так. Цей віджет відкриває детальний звіт за день, тиждень і місяць.

Чи передаються мої дані комусь?

Сайт не збирає токени. Скрипти на iPhone надсилають персональний токен лише API chatbot.respublika.pp.ua через HTTPS, а токен зберігається у Keychain. Журнали й графіки зберігаються локально.

Після очищення віджет показує «Script not found». Що робити?

Затисніть віджет → «Редагувати віджет» → «Script» → виберіть відповідний новий «Республіка · …». Старий скрипт міг бути перенесений в архів. Видаляти історію або перевстановлювати API не потрібно. Повна інструкція — вище.

Що робити, якщо щось не працює?

Напишіть автору в Telegram або створіть GitHub Issue. Зазначте, яка саме автоматизація чи віджет не працюють, але не публікуйте приватну інформацію.
